# Zumbido Rolante · Stand Automóvel

Site do stand Zumbido Rolante e da oficina Auto Neves.

- `index.html` — o site (página única, sem build)
- `img/` — imagens
- `supabase.sql` — base de dados, regras de segurança e viaturas de exemplo
- `admin.sql` — dá acesso de gestão a um utilizador

Gestão do stock: abrir o site com `#admin` no fim do endereço e entrar com o email do administrador.
